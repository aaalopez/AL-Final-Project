# FINtellect — Financial Literacy for Older Adults

An agentic Dash app that helps older adults (and the family members who support them) build financial confidence: plain-language 101 guides, myth-busting, a scam-checker, and personalized guidance for themselves and their kids.

## What it does

- **101s** — Plain-language explainers across Retirement, Loans, Savings, Social Security & Medicare, Estate Planning, Insurance, and Investments (the 11 investment types from [Fidelity's "What to invest in"](https://www.fidelity.com/learning-center/smart-money/what-to-invest-in) guide), generated by a Tutor Agent.
- **Misconceptions** — Common financial myths, corrected.
- **Common Questions** — FAQ-style questions aimed at middle-aged adults who feel behind on or unfamiliar with personal finance basics (debt vs. saving, late retirement starts, the "sandwich generation" squeeze, credit scores, etc.). Tapping a question expands the answer directly beneath it, from the Tutor Agent, in a non-judgmental tone, with a source link.
- **Common Scams** — A static reference list of frequent scam patterns and organizations scammers often impersonate (framed accurately: the real IRS/SSA/Medicare/etc. are legitimate — it's unsolicited contact claiming to be them that's the red flag), plus a **Scam-Checker Agent**: paste a suspicious text, email, or call transcript and get a plain-language risk read.
- **Ask a Loved One** — A Family-Bridge Agent turns a scam check or financial question into a plain-language summary addressed to one of the two trusted contacts saved on the Profile page, reminding them it's always okay to ask someone they trust first. A "Text this" link opens the user's own phone messaging app, addressed to that contact's saved number, with the message pre-filled — nothing is ever sent by the app itself.
- **Investing in My Kids** — Ways to save or invest on behalf of a child (529 plans, custodial accounts, Coverdell ESAs, Roth IRA for a working teen, education savings bonds, prepaid tuition, trusts, and building a savings habit), explained the same inline-expand way as Common Questions.
- **Ask a Question** — A free-form chat with a Chat Agent: sticks to facts (says plainly when it doesn't know a current/specific number rather than guessing), lays out relevant options instead of giving personal advice, and remembers earlier turns so you can describe your situation and follow up (this absorbed the old "For Me" section's purpose).
- **Profile** — A fully fictional, clearly-labeled demo profile with editable fields (age, city, state, filing status, savings, 401(k), retirement goal) and an Annual Income section with a line chart of income by year. The Goals section's "Illustrative savings target" is computed, not manually entered — it uses a traditional retirement-calculator rule (projects current income to the goal age at 3%/year raises, assumes 80% income replacement in retirement, then applies the standard 4%-withdrawal-rule 25x multiplier), so a later retirement goal age raises the target. Editing updates a "Save changes"-triggered shortfall estimate and the chart live. The Financial Snapshot section has "+ Link new bank/savings/retirement account" buttons that add another illustrative, editable account line (no real bank connection — this demo has no backend to connect to one). Credit Card Rewards has a "See redemption options" toggle per card showing an illustrative cash/flights/hotels/gift-cards breakdown. Stored only in the browser session (no backend, no agent call, no persistence beyond the tab) — reachable from the header, not the main sidebar.

## Agents

| Agent | Role | Model |
|---|---|---|
| Tutor Agent | Generates 101s, Misconceptions, Common Questions, and Investing in My Kids explanations | `gpt-6-luna` via Portkey |
| Scam-Checker Agent | Analyzes pasted suspicious content for scam red flags | `gpt-6-luna` via Portkey |
| Family-Bridge Agent | Converts agent output into a shareable family summary | `gpt-6-luna` via Portkey |
| Chat Agent | Open-ended factual Q&A; no fabricated facts, no advice | `gpt-6-luna` via Portkey |

Both the Tutor Agent (Common Questions) and Chat Agent cite sources using a shared whitelist in `agents/sources.py` — they may only link to a fixed set of top-level official homepages (irs.gov, ssa.gov, medicare.gov, etc.), never a specific sub-page, since a model-guessed deep link can't be verified and may not exist.

## Token/cost logging

Every model call is logged (not shown in the app UI) to `logs/usage_log.csv`: timestamp, which agent/function made the call, prompt/cached/completion/total tokens, and an estimated cost. This file is gitignored since it can contain pasted scam text. Use it to pull real, measured numbers for the report's Tokenomics section. Cost estimates use placeholder per-token rates in `data/pricing.py` — update those with the actual Portkey-billed rate before finalizing the report.

## Setup

1. Create and activate a virtual environment (already created at `.venv` in this folder):
   ```bash
   source .venv/bin/activate
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Add your Portkey API key. The app checks for `.env` in this folder first, then one level up. Copy `.env.example` to `.env` and fill in your key:
   ```bash
   cp .env.example .env
   ```
4. Run the app:
   ```bash
   python app.py
   ```
5. Open the URL printed in the terminal (defaults to `http://127.0.0.1:8050`).
